Converter — portable version
===========================

This folder is the whole application. Nothing is installed: keep the folder
where it is and run Converter.exe.

  * Converter.exe      the application (do not move it away from this folder:
                       it needs the "_internal" folder next to it).
  * _internal\         libraries, fonts, icons and ffmpeg/ffprobe.
  * licenses\          license texts of the bundled third-party components
                       (ffmpeg, Qt).
  * LICENSE            the license of Converter itself (MIT).
  * THIRD_PARTY_NOTICES.md
                       the components Converter is built on.

Settings, presets and conversion history are stored in %APPDATA%\Converter,
exactly like in the installed version.

Support and new versions: https://github.com/brighinatommaso-eng/Converter
