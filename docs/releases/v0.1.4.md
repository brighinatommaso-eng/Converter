# v0.1.4 - Linux packages, installer and a much lighter app

Converter 0.1.4 converts images, audio, video, data, documents and 3D models
**100% locally and offline**, with an honest lossless/lossy badge for every
target format. This release is about how you get it and how much it weighs.

## Downloads

| File | For | How |
|------|-----|-----|
| `Converter-v0.1.4-setup.exe` | **Windows** (new) | Run it: installs for your user only (no administrator rights), adds a Start menu entry, uninstalls from *Settings → Apps*. Running a newer setup updates it. |
| `Converter-v0.1.4-windows.zip` | Windows, portable | Extract the whole folder and run `Converter.exe`. |
| `converter_0.1.4_amd64.deb` | **Ubuntu, Debian, Mint** (new) | `sudo apt install ./converter_0.1.4_amd64.deb`, or double-click it. ffmpeg comes from your distribution. |
| `Converter-v0.1.4-x86_64.AppImage` | **Other Linux distros** (new) | `chmod +x Converter-*.AppImage` and run it. Needs glibc 2.35+ (Ubuntu 22.04, Debian 12, Fedora 36 and later). |

## A much smaller app

| | 0.1.3 | 0.1.4 |
|---|---|---|
| Windows (installed) | 956 MB | **403 MB** |
| Linux | — | **271 MB** |

- **pandoc is gone.** Markdown, HTML, EPUB, ODT and text are now converted by a
  built-in engine. It needs nothing installed and works in Portable mode too.
  Headings, emphasis, lists, tables, links, code and local images become native
  Word / OpenDocument / RTF / EPUB structure. Markdown → HTML follows the
  CommonMark/GitHub rules exactly.
- ffmpeg now ships as one shared set of libraries instead of two full copies.
- Parts of Qt the app never used (QML, PDF, virtual keyboard, translations)
  are no longer bundled.

## Honest about what changed

- Remote images in Markdown/HTML are **never downloaded** (the app works
  offline). They stay links in HTML/Markdown output. In Word, ODT, RTF and EPUB
  they are left out, and the badge tells you so.
- Raw HTML inside Markdown is cleaned: scripts, styles and unknown tags are
  removed, and the badge says so.
- The built-in engine is less complete than pandoc on Markdown footnotes, math
  and complex web-page layouts (CSS is not applied).
- DRM-protected EPUBs are refused with a clear message.

## Verification

- 426 automated tests pass on Linux (with ffmpeg and LibreOffice) and on Windows.
- Every package is tested before it can be released:
  - the Windows build runs its self-test, then the installer is installed
    silently, self-tested again and uninstalled;
  - the AppImage is self-tested on Ubuntu and on Fedora;
  - the `.deb` is installed, self-tested and removed.
- The executables are **not code-signed**. On Windows, SmartScreen may warn on
  first run: *More info* → *Run anyway*.
