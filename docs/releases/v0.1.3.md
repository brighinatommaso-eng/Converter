Third packaged Windows release. `Converter-v0.1.3-windows.zip` contains a
self-contained build of Converter 0.1.3 — images, audio, video, data, documents
and 3D models, converted **100% locally and offline**, with an honest
lossless/lossy badge for every target format.

This release comes from a full code review: every finding was fixed with a
regression test, and the PDF engine was measured on a set of 37 real-world PDFs.

## Honest badges (conversions that claimed LOSSLESS and weren't)

- **YAML → YAML** is now a byte copy: comments were deleted and `NO` became `false`.
- **CSV**: the real delimiter (`;` in European exports) and encoding (cp1252) are
  detected; duplicate column headers are kept instead of being renamed.
- **TXT → Markdown** keeps every line break and escapes Markdown symbols
  (pandoc used to re-flow the text).
- **WAV/FLAC** keep the source bit depth (24-bit, float) instead of truncating to
  16-bit; resampling, mono and loudness normalisation are declared as lossy.
- Dropped images, damaged PDF pages and undecodable characters are now declared
  in the badge instead of disappearing silently.

## Documents

- **PDF**: two-column papers no longer get a huge indent in Word; `-5 °C` is no
  longer turned into a bullet; short one-word PDFs are no longer mistaken for scans.
- **Damaged PDFs** that pdfminer rejected outright (malformed metadata, broken
  colour profiles) are now read; a single bad page is skipped and declared.
- **Borderless tables**: multi-line cells and merged row labels stay in one table
  (a 400-page manual went from 687 table fragments to 375 whole tables).
- **Scanned (fax/CCITT) PDFs** decode about 10× faster.
- **DOCX**: text inside tracked changes, fields, content controls, nested tables
  and text boxes is no longer lost.
- **Markdown/Word output**: full escaping, correct bold, mixed numbered/bulleted
  lists, numbered lists restart at 1.

## Images, audio, video, 3D

- Animated WebP/GIF/TIFF keep every frame; CMYK and 16-bit images convert instead
  of failing; small images can become 256 px icons; GIF keeps transparency.
- Video keeps **all** audio tracks and text subtitles; H.265 in MP4 plays on Apple
  devices; WebM without options no longer fails.
- Audio keeps cover art; loudness normalisation no longer jumps to 192 kHz.
- glTF is a single self-contained file; OBJ material files no longer overwrite
  each other in a batch.

## App

- **Cancel** now stops queued jobs.
- The size estimate no longer freezes the window; a typed output folder is used.
- Sensible default targets (JPG↔PNG, MP4, MP3, XLSX, DOCX) instead of alphabetical
  ones (BMP/AVI).
- The app icon now shows in the window title bar and taskbar.
- Format detection: a README with lists is Markdown again, not YAML.

## Build

- GPL/LGPL license texts for ffmpeg, pandoc and Qt are shipped next to
  `Converter.exe`.
- Unused optional libraries are no longer bundled (smaller download).

## Verification

- 398 tests pass; with the local 37-PDF corpus, 36 documents match their reviewed
  baselines and the password-protected one is refused with a clear message.
- Frozen build: `--selftest` PASS (27 checks) on Windows.

Windows SmartScreen may warn on first run: the executable is not code-signed
(*More info* → *Run anyway*).
